# Revisi CBT dari dua dokumen 25 Oktober 2026

Sumber: REVIEW CBT FIX.docx dan SISWA- REVIEW CBT FIX.docx yang diberikan pengguna.

## Pengelola

- Dashboard per peran, hitungan siswa/guru/rombel, tabel jenis kelamin dan wali kelas, agenda ujian.
- Siswa: filter unit untuk Super Admin; scope unit untuk Admin; kelas terkait untuk guru. Kolom tingkat, kelas dan wali. Impor Excel dan kartu akun.
- Kelas: tingkat SD 5–6, SMP/SMA 1–3, tahun, wali kelas, detail siswa/guru, impor Excel dengan validasi.
- Guru: data jenis kelamin, penugasan kelas/mapel dari master, perwalian dan akun otomatis. Admin Unit mengelola guru di unit sendiri; Super Admin mengelola semua.
- Mata pelajaran: tingkat, tabel kelas/guru, akses baca bagi guru. Mapel lama dapat diisi tingkatnya melalui Edit tingkat.
- Jadwal: master topik, judul, mapel, tingkat, pilihan banyak kelas, waktu WIB. Paket tidak wajib saat penjadwalan; guru menghubungkan soal kemudian.
- Bank: filter topik/tingkat/mapel, pembuat dan judul. Menu Bank disembunyikan dari guru; pemilihan bank tersedia dalam Buat soal.
- Buat soal: milik pembuat, pilih jadwal, Word/manual/salin dari bank; tersimpan ke bank dan terkait jadwal. Soal bertoken tetap terkunci.
- Monitoring: daftar ujian/status dan detail peserta, nilai, hasil, tindakan pengawas.
- Koreksi: objektif dihitung ulang dari kunci di server; isian/esai memiliki kata kunci dipisah titik koma, persentase awal, revisi poin proses. Guru mapel/korektor dapat publish. Wali kelas dapat mengekspor nilai terbit, tidak mengoreksi mapel di luar penugasan.

## Siswa

- Username dari unit dan NIS; password acak 12 karakter. Cetak ulang kartu dari Admin. Password disimpan sebagai hash untuk login dan terenkripsi untuk pencetakan, bukan teks biasa. Akun terhubung studentId lama.
- Dashboard, hitungan per topik/mapel, agenda hari ini, notifikasi, semua jadwal dan hasil terbit.
- Token baru 10 karakter tanpa huruf/angka yang mudah tertukar; token lama tetap berlaku.
- Checkbox identitas wajib sebelum MULAI, diverifikasi server.
- Mode keyboard matematika/fisika/kimia/Arab mengikuti pengaturan soal atau mapel.
- Pengumpulan manual: minimal ¼ durasi, semua jawaban valid/lengkap, tidak ada ragu-ragu. Waktu habis tetap mengumpulkan jawaban tersimpan otomatis.
- Selesai kembali ke dashboard bagi siswa yang login. Jalur token tanpa akun tetap tersedia untuk kompatibilitas.

## Verifikasi

`node tests/api.test.mjs`: basis data SQLite lokal, endpoint CBT dan endpoint login nyata dieksekusi dalam harness; validasi hak akses, riwayat, jadwal, soal, token dan penilaian.
`tsc --noEmit`: pemeriksaan tipe.
Browser QA komponen dashboard pengelola/siswa dan modal jadwal memakai fixture tanpa koneksi data; fixture dihapus sebelum publikasi.

Data lama yang belum memiliki jenis kelamin, tingkat, wali, topik atau pembuat tidak diberi nilai rekaan. Admin melengkapinya melalui menu terkait. Uji kapasitas jaringan sekolah dan penerimaan pengguna nyata tetap terpisah dari pengujian fungsi ini.
