# Pola soal SMA — 2 November 2026

Semua mapel SMA kelas X/XI/XII (tingkat internal 1/2/3) menggunakan tujuh pola dari dokumen TIFE-TIFE SOAL YANG BIASA DIPAKAI DI SMA.

1. Satu teks untuk beberapa pertanyaan.
2. Teks dan gambar tabel untuk beberapa pertanyaan.
3. Gambar berlabel untuk beberapa pertanyaan.
4. Infografik untuk beberapa pertanyaan.
5. PG kompleks MCMA opsi A–E.
6. PG dengan pilihan gambar.
7. Menjodohkan gambar dengan pernyataan.

Tipe jawaban bawaan: PG, PG_KOMPLEKS, MENJODOHKAN. Pola 1–4 dan 6 merupakan variasi PG. Semua mapel baru mendapat pilihan bawaan yang sama, dengan tambahan tipe per paket tetap tersedia. Master lama dimigrasi sekali per lingkup semester pada pembukaan dashboard oleh Super Admin/Admin Unit SMA. Perubahan admin berikutnya tidak ditimpa. Paket dan riwayat lama dipertahankan.

Kelompok bacaan menampilkan stimulus pada setiap pertanyaan terkait; pengacakan mempertahankan anggota kelompok. Tabel disajikan sebagai gambar, bukan sel yang dapat diedit. Label pada gambar disiapkan dalam gambar sumber. Gunakan Letak gambar untuk unggah ke pertanyaan, opsi, butir kiri/kanan. Maksimal delapan gambar per soal termasuk bacaan. Klik gambar memperbesar dalam dialog pada halaman yang sama. Pilihan pasangan bergambar ditampilkan sebagai daftar berlabel; dropdown memilih label pasangan.

MCMA tetap menggunakan skor tepat penuh atau nol. Guru menulis jumlah jawaban yang diminta pada instruksi pertanyaan dan menandai seluruh kunci. Sistem tidak membatasi checkbox ke jumlah tertentu. Tidak ada penskoran parsial baru.

Impor Word masih melalui pemeriksaan guru; tidak ada klaim bahwa semua layout Word bisa dikonversi otomatis secara identik. Naskah sumber tidak dipublikasikan. Uji API mencakup master semua tingkat, mapel baru, penyimpanan gambar pilihan/pasangan dan pelestarian SD/SMP. Uji browser editor memeriksa pola SMA, tujuan unggah gambar dan dialog pembesaran; tidak melakukan ujian produksi menggunakan akun siswa.
